# Application de Gestion de Stock - Couverture & Toiture

## 1. Description du projet
Cette application est destinée aux **couvreurs** (sur les chantiers) et aux **fournisseurs/gestionnaires**. 
Elle permet de gérer le stock de matériaux de couverture (zinc, tuiles, etc.) pour éviter les ruptures de stock sur les chantiers et anticiper les réapprovisionnements.

## 2. Pour qui ?
- **Le couvreur :** pour enregistrer ce qu'il utilise ou remet en stock sur le terrain.
- **Le fournisseur / gestionnaire :** pour suivre l'état du stock et savoir quand recommander du matériel.

## 3. Fonctionnalités principales
- **Gestion des produits :** Consulter la liste des matériaux (zinc, tuiles...) et leurs quantités disponibles.
- **Mouvements de stock :** 
  - Ajouter du stock (réception de commande).
  - Enlever du stock (utilisation sur un chantier).
- **Alerte de stock :** Savoir quand un produit passe sous un seuil critique pour contacter le fournisseur.
